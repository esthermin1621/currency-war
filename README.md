# ATI ATI · Currency Wars (ATI COIN)

화폐 변천사 프로젝트용 웹 시뮬레이션 게임(초등 1학년 기준). 왕·은행장·세무원·상점주인·백성 다섯 역할이 함께 6년 동안 나라의 돈을 운영하고, 퀘스트를 깨며 별을 모읍니다.
기획서는 [PRD.md](PRD.md), 개발 규칙은 [CLAUDE.md](CLAUDE.md)를 보세요.

```bash
npm install
npm run dev     # 게임 실행
npm test        # 엔진·밸런스 테스트
```

교사 모드 기본 PIN은 `1234`입니다. 화면 언어는 모두 영어(AR 2.3 수준)이고, 한국어 힌트는 교사 모드에서 켤 수 있습니다.
